# N5 physical-pair fidelity and cost evidence

Both native arms are **NOT QUALIFIED FOR GB10 A/B** on this evidence.
`evidence/strict-v1.json` preserves unchanged V1: 12 samples per arm, zero state
flags, zero unexplained, KL within 3x band, stage-0 attention excess fails.
Results exactly match N4's corrected same-key solo pilots. Every checked
pair/solo tensor, draft array and window metadata agrees bitwise.

`evidence/s20-yardstick.json` is a separate assessment. Against the available
same-key official-GPU-attention component control, kx2/packed s0 median errors
are 8.018x/8.363x control (required <=3x). The full official-GPU pipeline control
recommended by S20 does not exist. No GPU control was generated by N5.

The all-key/all-stage KV audit extends S20's r8/r11 inspection: r11 s0 has seven
one-step and one two-step FP8 differences at position 129, but r16-r19 introduce
larger differences (up to 4/9/64 signed code steps at stages 0/1/2). Thus S20's
literal 1–2-step clause does not clear the full capture. Maximum row norm error
is only .01323, below V1's .05 state tolerance; this is a separate clause failure,
not a rewritten V1 state verdict. Origins of all historical KV differences are
not proved by current main_x_P-only dumps. Current-position main_x differences
are not uniformly one BF16 step either (maximum 2 kx2 / 3 packed).

FP8 distances use the official 32-value blocks and exact common-scale
reconstruction, with signed zero merged. Original quantizer scales were not
saved; reconstructed common-scale encodability does not prove those originals
identical. The 64-step outlier crosses zero; code distance alone is not a
relative-error bound or proof of a semantic defect.

`evidence/telemetry.json` retains phase-tagged 1s SMI memory/power summaries,
startup times and both dump modes' logged mixed-case timings. The dump-off
synthetic local TCP mix p50 is 3.446 ms kx2 / 14.289 ms packed. Neither is a
B1/n5 or GB10 round-cost calibration. Full coordinator report and unchanged V1
outputs are outside Git in `/opt/dsv41/campaigns/DSV41-OFFLOAD/N5*`.

## Reproduce on Controller, CPU only

Inputs are private, never Git:

- Pair results: `/opt/dsv41/data/n5/pair-20261023T211932Z`
  (copied from X86host `~/dsv41-offload/n4/results/` with this exact name).
- Original V1 worktree, reference dumps, capture and checkpoint: paths below.
- Corrected N4 solo pilots, official component control and 36 reference-attention
  fixtures: `/opt/dsv41/data/n4`.

All 92 pair files were SHA256-checked against read-only X86host originals;
manifest and verification log are private under `/opt/dsv41/data/n5/`.
The strict collector verifies N4's original classifier/reference/wrapper pins.
No runtime or production source is changed by this lane.

From the N5 worktree, launch long classification detached in tmux. For each
`arm=native-hybrid-kx2` and `arm=native-packed`, execute:

```bash
source ~/.config/ndm/paths.sh
export CUDA_VISIBLE_DEVICES= OMP_NUM_THREADS=12 MKL_NUM_THREADS=12 PYTHONDONTWRITEBYTECODE=1
export TMPDIR=/opt/dsv41/data/n5
arm=native-hybrid-kx2
"$HARNESS_PYTHON" -m offload.dspark.native.tools.n3.classify \
  --verify-root /opt/dsv41/repos/.worktrees/dsv41-v1-verify/offload/dspark \
  --arm-dir "/opt/dsv41/data/n5/pair-20261023T211932Z/$arm-capture" \
  --arm-name "$arm" \
  --expected-keys @/opt/dsv41/campaigns/DSV41-OFFLOAD/N3-v1-keys.txt \
  --dumps /opt/dsv41/data/v1/dumps \
  --captures /opt/dsv41/data/v1/captures/A-capture-20261022 \
  --ckpt /opt/dsv41/data/v1/native-1017 \
  --official /opt/dsv41/data/ref-ds41/inference \
  --out "/opt/dsv41/campaigns/DSV41-OFFLOAD/N5-$arm-gates.json"
```

Each wrapper exits **1** for the failed attention gate. Preserve stdout/stderr
and the exit code as `N5-$arm-classify.log` / `.exit` in the campaign directory;
require a complete gate JSON before interpreting exit 1 as a measured failure.
A traceback or missing output is not a gate verdict.
