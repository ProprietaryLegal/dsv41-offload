## Reading against the SP1 decision rules

- None of these donors is a choice yet. The roadmap's rule stands: pick at most one target-work reduction from the
  SP1 trace budget.
- **Most likely to be justified** (if the trace confirms):
  - the #42718 idea, per-request verify width from the remote confidences (decode routed_moe/dense);
  - #43401's already-present candidate-only consumer scoring (decode attention at long context, if the DeepGEMM
    path runs on SM121).
- **Unlikely on GB10:** the prefill-graph donors (#43733/#43736). GB10 prefill chunks are GPU-bound, not
  launch-bound.
- **Not a time donor:** #42867 belongs with NB1; #44673 is already satisfied; the render server is a CPU-placement
  option with no expected GPU-bucket effect.
